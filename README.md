# IKÉASTRE · IKEA × Gen Z (B3CPD, Ynov)

Dossier commun de l'équipe (Loris, Tobias, Eliott). Projet académique indépendant, non affilié à IKEA.

## Récupérer le dossier (une seule fois)
Avec Git installé, dans le dossier où tu veux le mettre :
```
git clone https://github.com/eliotthaudiquert-ctrl/ikeastre.git
```
Ou demande simplement à ton Claude : « clone https://github.com/eliotthaudiquert-ctrl/ikeastre et lis le CLAUDE.md ».

## Au quotidien
- Double-clic sur **`Avancement.html`** : où en est le projet, ce qui reste, qui attend quoi.
- Double-clic sur **`Synchroniser.cmd`** : récupère le travail des autres et envoie le tien.
- Ton Claude lit automatiquement `CLAUDE.md` quand tu le lances dans ce dossier : il y trouve l'état du projet, les règles et le journal.
- Après chaque modif, ton Claude met à jour `avancement.js` (état + journal).

Pour pousser tes modifs, il faut qu'Eliott t'ajoute comme collaborateur sur GitHub (donne-lui ton pseudo GitHub).
